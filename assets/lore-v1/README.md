# Изображения стартового мира

Стиль: реалистичное средневековое фэнтези. Генератор: встроенный `image_gen`.

Лор: `../../specifications/lore/README.md`. Точные промпты и соответствие файлов сущностям: `manifest.json`. Галерея: `index.html` — открыть в браузере, установка зависимостей не требуется.

Пакет содержит 13 локаций, 13 NPC, 15 мобов, 3 образа классов, 6 предметов и 15 иконок умений. Уровни, имена, дроп и задания описаны в лоре; картинки сами по себе не подключают игровой контент к API или хранилищу.

Основной городской фон — площадь с уровня глаз игрока. Слева лавка и мастерская, справа ярмарка, стартовый NPC — мужчина-квартирмейстер, видимый в полный рост. Ранние варианты панорамы и площади с женщиной сохранены как черновики и не включены в актуальную галерею.

Встроенные в фон персонажи служат визуальному прототипу. Для кликабельных зон интерфейса понадобятся отдельные привязки; они пока не реализованы. Портреты NPC предназначены для диалогов. Сходство изображений двух миров намеренное, но биографии персонажей независимы.

Исходные PNG сохранены без изменения размера. Для включения в игру можно позже выбрать размер и формат под существующий интерфейс. Свойства выполнения хода не кодируются в иконках: баф или дебаф могут требовать своего хода, не завершая его.

После изменения реестра пересобрать галерею из корня проекта: `python3 assets/lore-v1/build_gallery.py`. Скрипт использует только стандартную библиотеку Python и не изменяет изображения.
