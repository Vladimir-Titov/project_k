# Спецификация персонажа v1

## 1. Назначение

Первая версия персонажа должна содержать минимальный набор данных, необходимый
для создания персонажа и последующего участия в пошаговом бою.

На этом этапе персонаж существует как самостоятельная сущность и не связан с
аккаунтом, локацией, инвентарём или другими игровыми системами.

## 2. Создание персонажа

При создании игрок указывает:

* имя;
* архетип.

В первой версии доступен один архетип:

```text
adventurer
```

Игрок не может самостоятельно передавать значения здоровья, атаки, защиты,
уровня или опыта. Они назначаются сервером в соответствии с выбранным
архетипом.

## 3. Поля персонажа

```text
id
name
archetype
level
experience
max_health
current_health
attack
defense
created_at
updated_at
```

Стартовые значения архетипа `adventurer`:

```text
level = 1
experience = 0
max_health = 100
current_health = 100
attack = 12
defense = 4
```

## 4. Правила и ограничения

### Имя

* длина после нормализации — от 3 до 24 символов;
* разрешены Unicode-буквы, цифры, пробел и дефис;
* имя должно начинаться и заканчиваться буквой или цифрой;
* несколько последовательных пробелов заменяются одним;
* пробелы в начале и конце удаляются;
* уникальность имени проверяется без учёта регистра.

### Числовые значения

* `level >= 1`;
* `experience >= 0`;
* `max_health > 0`;
* `0 <= current_health <= max_health`;
* `attack >= 0`;
* `defense >= 0`.

Значения характеристик хранятся непосредственно у персонажа. Архетип определяет
только их начальные значения и не должен повторно вычислять характеристики уже
созданного персонажа.

## 5. Предполагаемый API

### Создание

```http
POST /api/v1/characters
```

```json
{
  "name": "Arden",
  "archetype": "adventurer"
}
```

Успешный ответ:

```text
201 Created
```

Сервер возвращает созданного персонажа со всеми его публичными полями.

Ошибки:

* `409 Conflict` — нормализованное имя уже занято;
* `422 Unprocessable Entity` — имя или архетип не прошли валидацию.

### Получение

```http
GET /api/v1/characters/{character_id}
```

Ошибки:

* `404 Not Found` — персонаж не существует.

## 6. Не входит в первую версию

* аккаунт и авторизация;
* несколько персонажей на аккаунте;
* выбор или распределение характеристик;
* дополнительные архетипы и классы;
* навыки и способности;
* локация;
* состояния жизни и активности;
* экипировка и инвентарь;
* восстановление здоровья;
* повышение уровня;
* редактирование и удаление персонажа.

## 7. Критерии готовности будущей реализации

* персонаж создаётся только с серверными значениями архетипа;
* имя нормализуется и проверяется на уникальность без учёта регистра;
* некорректные характеристики невозможно сохранить;
* созданного персонажа можно получить по идентификатору;
* модель можно преобразовать в состояние участника боя без зависимости боевого
  движка от базы данных.
