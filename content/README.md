# Пробные умения классов

Каталог — `content/skills.json`. Иконки — `output/skill-icons/webp-256` (256×256).
Папка `mage` соответствует существующему коду класса `magician`.

```sh
# Проверить файлы и формулы, показать состав классов без записи данных.
uv run python seed_content.py --dry-run

# Наполнить локальные PostgreSQL и RustFS из .env.
docker compose up -d --wait
uv run alembic upgrade head
uv run python seed_content.py
```

Нужны `S3_ENABLED=true` и для локального RustFS `S3_INITIALIZE_LOCAL_BUCKET=true`.
Скрипт загружает выбранные WebP в `images/skills/`, заполняет `image_url` действий
и эффектов, обновляет названия/описания классов, назначает умения классам и уже
созданным активным персонажам. Характеристики и здоровье персонажей не меняются.

Повторный запуск обновляет записи этого каталога без дублирования ID, правил
или связей. URL картинки включает хеш её содержимого: повторная загрузка того же
файла сохраняет URL, изменённая картинка получает новый. Старые картинки не удаляются.
Запись контента в БД выполняется одной транзакцией; загрузка файлов предшествует ей.
Если запись БД не удалась, повторите команду после исправления ошибки.

Общие тестовые `basic_attack` и `rage` снимаются с этих трёх классов и их активных
персонажей через архивирование связей; сами старые определения и прочие умения
сохраняются. Правки управляемых каталогом умений через админку будут заменены
значениями JSON при повторном импорте.

После обновления кода перезапустите приложение. Начните **новый бой**: уже начатые
бои продолжают использовать сохранённые снимки умений.

## Наборы

- **Маг (7):** огненный шар, ледяная стрела, цепная молния, магический щит,
  лечение, проклятие, оковы.
- **Воин (6):** удар, блок, ярость, усиление, пробитие брони, кровотечение.
- **Путешественник (7):** выстрел, множественный выстрел, скрытность, ускорение,
  ловушка, отравление, выживание.

Пропущены `warrior/dash`, `mage/teleportation`, `warrior/protect-allies`,
`adventurer/scouting`: перемещения, союзников и исследования в текущей дуэли нет.
Цепная молния и множественный выстрел делают три последовательных попадания в
одного противника. Скрытность и ускорение — временные бонусы характеристик;
оковы ослабляют атаку. Они не меняют очередность ходов и не добавляют перемещение.

Урон, лечение, бонусы и штрафы используют существующие `health`, `attack`, `defense`
и формулы `expression_v1`. Значения пробные; точные формулы и описания находятся в JSON
и доступны после импорта в админке.

## Периодические эффекты

Единственное расширение движка: правила `resource_delta` у эффекта с длительностью
`turns` выполняются **в конце хода носителя**, в том числе при таймауте. Срабатывание
идёт до уменьшения длительности, поэтому последний ход тоже наносит урон/лечит.
В ход наложения новый эффект не срабатывает. Повторное наложение обновляет срок
без суммирования одинаковых эффектов — существующая политика `refresh`.

- Кровотечение: 3 урона × 3 хода носителя.
- Яд: 2 урона × 4 хода носителя.
- Оковы: 3 урона в конце одного хода вместе с ослаблением атаки.
- Восстановление от выживания: 3 здоровья × 3 собственных хода.

Мгновенная часть этих умений оформлена отдельным эффектом. Лечение ограничивается
максимальным здоровьем. Смертельный периодический урон завершает бой и при таймауте.
Для аналогичного эффекта достаточно в админке выбрать `turns`, число ходов и правило
`resource_delta` для `health` с отрицательной (урон) или положительной (лечение) формулой.
Новые модели и миграции не требуются.
