# Иконки умений Project K

24 иконки из предоставленного атласа, по 8 для мага, воина и путешественника.
Изображения нарезаны из исходника без перерисовки; заголовки классов и подписи
исключены из ячеек. Сохранены исходная прозрачность и локальное свечение.
Рисунок вписан в квадрат с отступами, чтобы иконки удобно размещались в кнопках.

## Что загружать через админку

- `webp-256/` — рекомендуемый вариант для загрузки: 256×256 px, прозрачный фон,
  подходит для текущих кнопок и более крупных изображений в будущем.
- `webp-128/` — облегчённый вариант: 128×128 px, подходит для небольших иконок
  действий и эффектов. Весь набор весит около 193 КБ.
- `png-256/` — PNG 256×256 px с прозрачностью для дальнейшей обработки
  или загрузки, если админка не принимает WebP.

WebP экспортирован с качеством 92. PNG сохранён без потерь после масштабирования.
Каждая папка содержит подкаталоги `mage`, `warrior` и `adventurer`.
Латинские имена файлов обозначают рисунки и не привязаны к кодам действий API.
После загрузки полученный URL можно указать в `image_url` действия или эффекта.

`preview-dark.png` показывает весь набор на фоне арены;
`preview-transparency.png` — на шахматной подложке. Эти два файла являются
обзорными изображениями, их не нужно загружать как иконки.

`manifest.json` содержит русские названия, пути, размеры файлов, координаты
нарезки и SHA-256 исходного атласа.
